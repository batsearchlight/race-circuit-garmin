# Security policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Use
GitHub's **Report a vulnerability** option in the repository's Security tab so
the report and follow-up remain private.

Include the affected version, watch model, reproduction steps, and potential
impact. Please avoid including real credentials, personal health data, or other
sensitive information in the report.

## Scope

The app runs locally on a Garmin watch and has no network integration, account
system, analytics, or server component. Reports about unsafe handling of sensor
data, release artifacts, build credentials, or third-party dependencies are in
scope.
